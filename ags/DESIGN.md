# AGS Design System

## Layout

```
style.scss              index, only @use lines
colors.scss             GENERATED by matugen — edit ~/.config/matugen/templates/ags-colors.scss
styles/_tokens.scss     spacing, radii, type, motion, state layers, semantic colors
styles/_mixins.scss     flat-button, interactive, tile, on-state, panel, notif-text, track
styles/_base.scss       globals: transitions, .glyph, .sep, .pulse
styles/_<widget>.scss   one partial per widget (bar, popovers, notifications, media, quicksettings, pomodoro, …)
```

Each partial starts with:

```scss
@use "../colors" as *;
@use "tokens" as *;
@use "mixins" as *;
```

## Color roles (Material 3, from matugen)

| Use | Token |
|-----|-------|
| Bar background | `$bar-bg` (`rgba($surface, .55)`) |
| Popovers, cards, toasts, OSD | `$panel-bg` (`rgba($surface-container, .82)`) via `@include panel` |
| Tiles/rows inside a panel | `$card-bg` (`$surface-container-high`) |
| Slider / progress troughs | `$track-bg` (`$surface-container-highest`) |
| Primary text | `$text` (`$on-surface`) |
| Secondary text | `$text-muted` (`$on-surface-variant`) |
| Placeholder / disabled | `$text-faint` (`$outline`) |
| Separators, hairlines | `$outline-variant` |
| Accent (fills, active dots, progress) | `$primary` / `$on-primary` |
| List selection (launcher row, audio device) | `$secondary-container` / `$on-secondary-container` |
| Break / secondary accent (pomodoro) | `$tertiary` / `$on-tertiary` |
| Destructive | `$error` / `$on-error` |
| Urgent / critical (urgent workspace pip, critical notification edge) | `$error` |

Never hardcode a hex or `rgba(<number>…)` — both break when matugen switches to light mode.

## State layers

Interactive elements overlay `$on-surface` at fixed alphas:

| State | Token | Alpha |
|-------|-------|-------|
| hover | `$state-hover` | .08 |
| pressed | `$state-pressed` | .12 |
| selected | `$state-selected` | .16 |

`@include interactive($radius)` applies these to a transparent button. `@include tile($radius)` does the same on a `$card-bg` fill.

## On-state rule

Every toggle that is **on** — QS tiles, Wi-Fi/BT halves, the Dark/Light segment, Caffeine, the pomodoro play button — uses `@include on-state`: solid `$primary` background with `$on-primary` content. List selection is the exception: it uses `$secondary-container`, so it doesn't compete with the toggles.

## Spacing, radii, type

- Spacing: 4px grid, `$spacing-1` (4) … `$spacing-8` (40).
- Radii: `$radius-xs` 4, `-sm` 8 (bar items, menu items), `-md` 12 (bar body, rows), `-lg` 16 (panels, tiles), `-xl` 20, `-full` 999 (pills, dots, badges).
  Nested radius = outer radius − padding (a card with `-lg` and 8px padding gets `-sm` children).
- Type: `$font-size-base` 12 for secondary, `-lg` 13 for bar/UI, `-2xl` 15 for titles and entries.
- Icons: everything is 16px (`$icon-size`; `$glyph-size` aliases it). Glyphs use `$font-icon` (JetBrainsMono Nerd Font **Propo**): in the plain Nerd Font variant the glyph's ink is wider than its advance, which pushes icons off-centre in their highlight.

## Bar

Every bar item is `$bar-item-h` (24px) tall and shares `interactive($radius-sm)`.

- Icon-only buttons (launcher, caffeine, power, tray) are 24×24 squares with the icon centred.
- Text or composite buttons (bell, pomodoro, QS pill) use `padding: 0 $spacing-2`. Static items (clock, battery, window title) use the same padding with no hover.
- Gaps inside an item: `$spacing-1` between sibling icons (QS pill, tray) and `$spacing-2` between an icon and its text (battery, bell count, clock date).
- Clock and bell are one item (`DateMenu`): its popover holds grouped notifications and a calendar.
- The media pill (`widget/media`) sits after the date menu and only exists while an MPRIS player does.
- Workspaces: at least five pips, growing to the highest workspace in use; `.occupied`, `.active` and `.urgent` (pulsing `$error`) states, plus a ring for the scratchpad. Each button fills the bar height with `$spacing-1` side padding, and the 8px `.pip` inside is only the visual. This keeps the click target large.
- Separators are `$outline-variant` with an 8px side margin.

## Motion

AGS owns all shell motion. Hyprland's `ags-no-anim` layer rule disables its animations on every AGS namespace (it still blurs them). Hyprland only animates windows and workspaces.

| Token (SCSS) | `MOTION` (TS) | Use |
|---|---|---|
| `$dur-fast` 160ms | `fast` | small state changes |
| `$dur` 220ms + `$ease` | `base` | hover/state transitions, revealers |
| `$dur-enter` 280ms + `$ease` | `enter` | surfaces appearing |
| `$dur-exit` 180ms + `$ease-in` | `exit` | surfaces leaving |

`widget/common/motion.ts` mirrors the tokens. `enter(w)` adds `.in` on the next frame; `exit(w, done)` adds `.out` and runs `done` (usually hiding the window) after `MOTION.exit`. Keyframes:

- `surface-in` / `surface-out`: launcher, files, clipboard and wallpapers cards, plus bar popovers (enter only)
- `slide-in-x` / `slide-out-x`: toasts and the screenshot preview
- `rise-in` / `rise-out`: OSD
- `fade-in` / `fade-out`: overview

Never hard-code a duration. Use a token in SCSS and `MOTION.*` in TS.

## Fields

Text entries use `@include field`: a translucent `rgba($surface, .5)` fill, so the layer blur shows through. It never uses `$card-bg`.
