# AGS Design System

## Layout

```
style.scss              index, only @use lines
colors.scss             GENERATED by matugen — edit ~/.config/matugen/templates/ags-colors.scss
styles/_tokens.scss     spacing, radii, type, motion, state layers, semantic colors
styles/_mixins.scss     flat-button, interactive, tile, on-state, panel, notif-text, track
styles/_base.scss       globals: transitions, .glyph, .sep, .pulse
styles/_<widget>.scss   one partial per widget (bar, popovers, quicksettings, pomodoro, …)
```

Each partial starts with:

```scss
@use "../colors" as *;
@use "tokens" as *;
@use "mixins" as *;
```

## Color roles (Material 3, from matugen)

| Use | Token |
|-----|-------|
| Bar background | `$bar-bg` (`rgba($surface, .55)`) |
| Popovers, cards, toasts, OSD | `$panel-bg` (`rgba($surface-container, .82)`) via `@include panel` |
| Tiles/rows inside a panel | `$card-bg` (`$surface-container-high`) |
| Slider / progress troughs | `$track-bg` (`$surface-container-highest`) |
| Primary text | `$text` (`$on-surface`) |
| Secondary text | `$text-muted` (`$on-surface-variant`) |
| Placeholder / disabled | `$text-faint` (`$outline`) |
| Separators, hairlines | `$outline-variant` |
| Accent (fills, active dots, progress) | `$primary` / `$on-primary` |
| List selection (launcher row, audio device) | `$secondary-container` / `$on-secondary-container` |
| Break / secondary accent (pomodoro) | `$tertiary` / `$on-tertiary` |
| Destructive | `$error` / `$on-error` |

Never hardcode a hex or `rgba(<number>…)` — both break when matugen switches to light mode.

## State layers

Interactive elements overlay `$on-surface` at fixed alphas:

| State | Token | Alpha |
|-------|-------|-------|
| hover | `$state-hover` | .08 |
| pressed | `$state-pressed` | .12 |
| selected | `$state-selected` | .16 |

`@include interactive($radius)` applies these to a transparent button. `@include tile($radius)` does the same on a `$card-bg` fill.

## On-state rule

Every toggle that is **on** — QS tiles, Wi-Fi/BT halves, the Dark/Light segment, Caffeine, the pomodoro play button — uses `@include on-state`: solid `$primary` background with `$on-primary` content. List selection is the exception: it uses `$secondary-container`, so it doesn't compete with the toggles.

## Spacing, radii, type

- Spacing: 4px grid, `$spacing-1` (4) … `$spacing-8` (40).
- Radii: `$radius-xs` 4, `-sm` 8 (bar items, menu items), `-md` 12 (bar body, rows), `-lg` 16 (panels, tiles), `-xl` 20, `-full` 999 (pills, dots, badges).
  Nested radius = outer radius − padding (a card with `-lg` and 8px padding gets `-sm` children).
- Type: `$font-size-base` 12 for secondary, `-lg` 13 for bar/UI, `-2xl` 15 for titles and entries.
- Icons: `$icon-size` 16px for symbolic icons, `$glyph-size` 15px for Nerd Font glyphs.

## Bar

Every clickable bar item (launcher, bell, tray, pomodoro, QS, caffeine, power) shares one rule: `interactive($radius-sm)`, `padding: 0 $spacing-2`, `min-height: 24px`. Static items (clock, battery, window title) get the same horizontal padding with no hover. Separators are `$outline-variant` with an 8px side margin.
